# Проєкт: Мій помічник у дієті (моя дієта)

## 1. Загальний опис та мета
Додаток для полегшення дотримання дієти для мого сина (має ФКУ — фенілкетонурію). 
* **Основна мета:** ведення архіву записів спожитих продуктів/страв та відображення кількості калорій, фенілаланіну (ФА), води та інших нутрієнтів для контролю показників крові.
* **Масштабування:** додаток створюється корисним і для людей з іншими орфанними та хронічними захворюваннями, де строга чи помірна дієта є запорукою фізичного та психічного здоров'я.

## 2. Дерево та структура проєкту (lib/)
* **Головний файл:** `main.dart`
* **Екрани (screens):** 
  * `splash_screen.dart` — Екран заставки (splash з логотипом `splash_ligo_widget.dart`).
  * `main_screen.dart` — Головний робочий екран (каркас з верхньою панеллю та правим виринаючим меню).
* **Віджети (widgets/main_screen/):**
  * `main_app_bar_widget.dart` — Верхня панель (AppBar).
    * `main_app_bar_widget/app_drawer_widget.dart` — Праве виринаюче меню (`endDrawer`) з налаштуваннями та профілем.
  * `calendar_widget.dart` — Головний віджет календаря.
    * `calendar_widget/date_picker_dialog.dart` — Вкладений віджет вибору дати.
  * `banner_widget.dart` — Банер на головному екрані.
  * `daily_summary_widget.dart` — Зведення за день (нутрієнти, калорії, ФА) з динамічним розрахунком кількості карток залежно від висоти.
  * `family_notes_widget.dart` — Сімейні нотатки.

## 3. Бази даних та структури (у розробці)
1. *Академічна база:* перевірені дані по базових продуктах (овочі, фрукти тощо) від дослідницьких інститутів.
2. *База готових продуктів:* фабричні товари, етикетки (випічка, солодощі, сири тощо).
3. *Мої страви (користувацькі рецепти):* власні рецепти з підрахунком нутрієнтів на 100 г готової страви, з відстеженням залишків для розуміння потреби готувати знову.
4. *Динамічна база наявних продуктів:* напівфабрикати та залишки для майбутньої функції генерації порад «що приготувати з того, що є вдома».

## 7. Візуальна індикація критичних показників та норм (13.08.2026)

- **Динамічний розрахунок кратності**: При перевищенні ліміту під смужкою автоматично з'являється числовий підпис (наприклад, «Перевищення у 2.3 раза!»).
- **Глобальні сповіщення**: Впровадено загальну систему інформування — якщо хоча б один критичний показник виходить за червону межу, на початку віджета виводиться попереджувальний блок.

Першими у списку виводяться точні збіги назви продукту, далі — продукти, назва яких починається із шуканого слова (наприклад, «Яблуко...»), після чого застосовується стандартне алфавітне сортування.

### Правила іменування файлів та структури тека-віджет:
1. **Принцип материнської теки:** Якщо віджет (наприклад, `main_app_bar_widget.dart`) розбивається на менші підкомпоненти, для нього створюється тека з аналогічною назвою без розширення (`main_app_bar_widget/`), куди складаються вкладені елементи (`app_drawer_widget.dart`).
2. **Суфікси у папці `widgets/`:** Усі файли всередині каталогу `widgets/` обов'язково мають закінчуватися на `_widget.dart`.
3. **Чистота моделей:** Чисті класи даних та моделей (наприклад, `NoteModel`), що виноситимуться у глобальне використання, зберігаються у папці `lib/models/` із суфіксом `_model.dart`.
